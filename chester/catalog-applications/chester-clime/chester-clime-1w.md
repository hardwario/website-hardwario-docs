# CHESTER Clime 1W

**CHESTER Clime 1W** is the variant of [**CHESTER Clime**](index.md) for multiple external **DS18B20** 1-Wire temperature probes.

:::info Firmware

This variant runs the main **[CHESTER Clime firmware](../../firmware/chester-clime/index.md)**, which has DS18B20 1-Wire support built in.

:::

## Differences from CHESTER Clime

- Measures temperature with several DS18B20 1-Wire probes instead of the CHESTER-S2 hygrometer.
- The enclosure has 8 cable glands for the probe cables.

## Hardware

The hardware of this application consists of the following ordering codes:

* `CHESTER-M-BCGLS`: Standard mainboard
* `CHESTER-E8-LP`: Enclosure with 8 cable glands (RM8L-4S)

See [**Ordering Codes**](../../ordering-codes.md) for more details.
