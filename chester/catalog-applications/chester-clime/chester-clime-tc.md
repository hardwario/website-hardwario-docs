# CHESTER Clime TC

**CHESTER Clime TC** is the variant of [**CHESTER Clime**](index.md) for two external **type K** thermocouples.

:::info Firmware

This variant runs the **[CHESTER Clime TC firmware](../../firmware/chester-clime/chester-clime-tc.md)**.

:::

## Differences from CHESTER Clime

- Measures temperature with two type K thermocouples on the **CHESTER-X3B** module instead of the CHESTER-S2 hygrometer.
- The enclosure has 2 PG7 cable glands for the thermocouple cables.

## Hardware

The hardware of this application consists of the following ordering codes:

* `CHESTER-M-BCGLS`: Standard mainboard
* `CHESTER-X3B:A`: 2x Type K thermocouple interface
* `CHESTER-E13-LP`: Enclosure with SMA pigtail and 2 cable PG7 glands

See [**Ordering Codes**](../../ordering-codes.md) for more details.
