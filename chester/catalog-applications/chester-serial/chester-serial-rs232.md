# CHESTER Serial RS-232

**CHESTER Serial RS-232** is the variant of [**CHESTER Serial**](index.md) with the **CHESTER-X12** extension module. It is intended for point-to-point communication with a single peripheral device, legacy equipment, or sensors requiring a direct serial link.

:::info Firmware

This variant runs the **[CHESTER Serial RS-232 firmware](../../firmware/chester-serial/chester-serial-rs232.md)**, which works with the MicroSENS 180-HS CO₂ sensor and the Promag MF7S RFID reader.

:::

## Differences from CHESTER Serial

* **Interface:** Non-isolated RS-232
* **Topology:** Point-to-point connection
* **Capacity:** Single device (1:1 connection)

## Hardware

The hardware of this application consists of the following ordering codes:

* `CHESTER-M-CGLS`: Standard mainboard
* `CHESTER-X12`: RS-232 interface module
* `CHESTER-E2-LP`: Enclosure with SMA pigtail

See [**Ordering Codes**](../../ordering-codes.md) for more details.
