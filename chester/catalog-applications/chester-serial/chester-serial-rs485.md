# CHESTER Serial RS-485

**CHESTER Serial RS-485** is the variant of [**CHESTER Serial**](index.md) with the **CHESTER-X2** extension module. It is designed for standard industrial bus communication where multiple devices are connected in a daisy-chain topology.

:::info Firmware

This variant runs the **[CHESTER Serial RS-485 firmware](../../firmware/chester-serial/chester-serial-rs485.md)**.

:::

## Differences from CHESTER Serial

* **Interface:** Non-isolated RS-485
* **Topology:** Multi-drop bus
* **Capacity:** Up to 8 Modbus RTU slave devices

## Hardware

The hardware of this application consists of the following ordering codes:

* `CHESTER-M-CGLS`: Standard mainboard
* `CHESTER-X2`: RS-485 interface module
* `CHESTER-X10`: External power input (5–28 V DC)
* `CHESTER-E2-LP`: Enclosure with SMA pigtail

See [**Ordering Codes**](../../ordering-codes.md) for more details.
