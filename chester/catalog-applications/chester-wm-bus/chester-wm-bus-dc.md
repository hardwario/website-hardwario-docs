# CHESTER wM-Bus DC

**CHESTER wM-Bus DC** is the variant of [**CHESTER wM-Bus**](index.md) powered from an external 230 V adapter.

:::info Firmware

This variant runs the main **[CHESTER wM-Bus firmware](../../firmware/chester-wm-bus/index.md)**.

:::

## Differences from CHESTER wM-Bus

- Externally powered by a 230 V DC adapter instead of six alkaline "D" cells.
- The mainboard has supercapacitors (`CHESTER-M-CS` instead of `CHESTER-M-CES`).
- Suits the configurations that the [**Example Configurations**](../../firmware/chester-wm-bus/index.md#example-configurations) mark as unsuitable for the battery variant.

## Hardware

The hardware of this application consists of the following ordering codes:

* `CHESTER-M-CS`: Standard mainboard w/ supercapacitors
* `CHESTER-B1-DLW`: B1 board with six D cell holders for lithium cells and the wM-Bus module

See [**Ordering Codes**](../../ordering-codes.md) for more details.
