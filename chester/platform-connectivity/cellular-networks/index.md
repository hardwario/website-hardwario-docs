# Mobile Networks

The **CHESTER** platform supports **LTE-M** and **NB-IoT** cellular technologies using the **nRF9160** System-in-Package from **Nordic Semiconductor**.

## Where to start

| Chapter | Use it when |
| :------ | :---------- |
| [**SIM Card Setup**](sim-card-setup.md) | You have a device and a SIM card and you want it on the network. Start here. |
| [**Configuration Parameters**](configuration-parameters.md) | You need to know what an individual `lte config` parameter does and which values it accepts. |
| [**Network Requirements**](network-requirements.md) | You are evaluating a network or an operator you have not used before, or you need to send a requirements checklist to a provider. |
| [**Vodafone SIM EU28+2**](vodafone-coverage.md) | You use a **HARDWARIO** Vodafone SIM card and need the PLMN ID or APN for a specific country. |
| [**Diagnostics and Troubleshooting**](diagnostics.md) | The device will not register and you need to see which networks are actually available at the site. |

## SIM cards

At **HARDWARIO**, we do not restrict customers to any particular SIM card provider, as long as the selected carrier offers one of the supported cellular technologies. For SIM cards provided by **HARDWARIO**, we can offer an extended level of technical support.

We can currently deliver SIM cards for these two carriers:

* **Vodafone** in European countries.
* **1NCE** for other providers in non-European countries.

:::caution

We only support the **Nano-SIM** form factor (4FF) for plastic SIM cards. Alternatively, **HARDWARIO** can provide a SIM chip variant (MFF2) for bulk orders.

:::
