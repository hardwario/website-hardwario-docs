# Výpočetní platforma {#processing-platform}

Zařízení **FIBER** je postavené na modulu **Raspberry Pi Compute Module 4 (CM4)**, spolehlivé výpočetní platformě s architekturou ARM a rozsáhlou podporou linuxového ekosystému. Díky tomu je možná dlouhodobá údržba, široká kompatibilita s aplikacemi a flexibilní vývoj vlastního firmwaru.

Klíčové vlastnosti:

* Čtyřjádrový Cortex-A72 (ARMv8, 64bitový) @ 1,8 GHz
* Varianty pamětí: 1/2/4/8 GB RAM a úložiště eMMC 8/16/32 GB
* Varianty pro průmyslový teplotní rozsah
* Kompatibilita s upstreamovými balíčky Linuxu a standardními vývojovými postupy
