# Výpočetní platforma {#processing-platform}

**FIBER** je postaven na modulu **Raspberry Pi Compute Module 4 (CM4)**, který poskytuje spolehlivou výpočetní platformu na architektuře ARM s rozsáhlou podporou linuxového ekosystému. To umožňuje dlouhodobou údržbu, širokou kompatibilitu aplikací a flexibilitu při vývoji vlastního firmwaru.

Klíčové vlastnosti:

* Čtyřjádrový Cortex-A72 (ARMv8, 64bitový) @ 1,8 GHz
* Varianty pamětí: 1/2/4/8 GB RAM a úložiště eMMC 8/16/32 GB
* Varianty pro průmyslový teplotní rozsah
* Kompatibilita s balíčky z upstreamu Linuxu a standardními vývojovými postupy
