# Uživatelské rozhraní {#user-interface}

**FIBER** nabízí několik lokálních rozhraní navržených pro přehlednost a rychlou diagnostiku:

### LCD displej {#lcd-display}

* Podsvícený grafický displej
* Zobrazuje hodnoty senzorů v reálném čase a diagnostiku zařízení

### Tlačítka {#buttons}

* Ovládací prvky pro navigaci a potvrzování
* Vhodné pro obsluhu na místě bez externích nástrojů

### Stavové LED {#status-leds}

* Jedna LED na každý port 1-Wire
* Vizuální indikace přítomnosti senzoru, aktivity a chyb

### Akustický bzučák {#acoustic-buzzer}

* Poskytuje zvukové výstrahy
* Užitečný pro alarmy nebo zpětnou vazbu při konfiguraci
