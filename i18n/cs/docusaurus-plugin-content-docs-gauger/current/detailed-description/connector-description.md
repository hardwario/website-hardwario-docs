# Popis konektorů {#connector-description}

Zařízení má dvě svorkovnice. První obsahuje dva redundantní páry pinů pro napájení. Druhá slouží k připojení digitálních vstupů. Má celkem osm pinů – kladný a zemní pin pro každý vstup.

Deska dále obsahuje port RJ-45 pro Ethernet, konektor SMA pro připojení bezdrátové antény, konektor Mini USB-B a 10pinový konektor JTAG na spodní straně DPS.
