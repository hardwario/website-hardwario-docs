# Popis konektorů {#connector-description}

Zařízení má dvě svorkovnice. Na první jsou dva redundantní páry napájecích pinů. Druhá slouží k připojení digitálních vstupů a má celkem osm pinů, pro každý vstup jeden kladný a jeden zemní.

Na desce je dále port RJ-45 pro Ethernet, konektor SMA pro bezdrátovou anténu, konektor Mini USB-B a na zadní straně DPS 10pinový konektor JTAG.
