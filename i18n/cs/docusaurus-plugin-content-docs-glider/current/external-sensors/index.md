# Externí senzory {#external-sensors}

GLIDER kromě interních senzorů přijímá i několik typů externích vstupů:

- **Teplotní sondy DS18B20** na sběrnici 1-Wire: viz [**Teplotní senzory**](temperature.md).
- **Digitální vstupy** CH1 / CH2: viz [**Konfigurace → Digitální vstupy**](../configuration.md#digital-inputs).
- **Zařízení Modbus RTU** na izolovaném portu RS-485: viz [**Příkazy shellu**](../commands/shell-commands.md).

Níže vyberte příslušnou stránku, kde najdete zapojení, konfiguraci a příklady příkazů.
