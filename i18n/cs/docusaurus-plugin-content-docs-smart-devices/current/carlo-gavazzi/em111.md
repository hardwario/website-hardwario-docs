# Carlo Gavazzi EM111 {#carlo-gavazzi-em111}

![Carlo Gavazzi EM111](/img/smart-devices/carlo-gavazzi-em111.webp)

**EM111** je kompaktní jednofázový elektroměr společnosti [Carlo Gavazzi](https://www.gavazziautomation.com/) na lištu DIN. Má certifikaci pro fakturační měření energie a komunikuje přes Modbus RTU.

## Klíčové parametry {#key-specifications}

| Parametr | Hodnota |
|---|---|
| Fáze | 1fázový, 2vodičový |
| Proud | Přímé připojení až 32 A |
| Napětí | 230 V AC (50/60 Hz) |
| Přesnost | Třída 1 (činná energie), certifikace MID |
| Komunikace | Modbus RTU (RS-485) |
| Displej | LCD, 7místný |
| Montáž | Na lištu DIN (2 moduly) |
| Certifikace | MID (certifikát ES), CE |

## Měřené parametry {#measured-parameters}

- Činná energie (kWh import/export)
- Činný výkon (W)
- Napětí (V), proud (A), účiník

## Integrace s HARDWARIO {#hardwario-integration}

Elektroměr EM111 se k zařízením HARDWARIO připojuje přes **Modbus RTU** (RS-485):

- **GAUGER**: Zařízení GAUGER čte z elektroměru EM111 registry Modbus RTU a data o energii odesílá do HARDWARIO Cloud.
- **CHESTER**: Zařízení CHESTER s rozšiřujícím modulem RS-485 může elektroměr EM111 pravidelně vyčítat a data přeposílat přes NB-IoT nebo LTE-M.
