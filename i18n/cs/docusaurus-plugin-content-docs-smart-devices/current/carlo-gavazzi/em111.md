# Carlo Gavazzi EM111 {#carlo-gavazzi-em111}

![Carlo Gavazzi EM111](/img/smart-devices/carlo-gavazzi-em111.webp)

**EM111** je kompaktní jednofázový elektroměr na DIN lištu od [Carlo Gavazzi](https://www.gavazziautomation.com/), certifikovaný pro fakturační měření energie s komunikací Modbus RTU.

## Klíčové parametry {#key-specifications}

| Parametr | Hodnota |
|---|---|
| Fáze | 1fázový, 2vodičový |
| Proud | Přímé připojení až 32 A |
| Napětí | 230 V AC (50/60 Hz) |
| Přesnost | Třída 1 (aktivní energie), certifikace MID |
| Komunikace | Modbus RTU (RS-485) |
| Displej | LCD, 7místný |
| Montáž | DIN lišta (2 moduly) |
| Certifikace | MID (certifikát EC), CE |

## Měřené parametry {#measured-parameters}

- Aktivní energie (kWh import/export)
- Aktivní výkon (W)
- Napětí (V), proud (A), účiník

## Integrace s HARDWARIO {#hardwario-integration}

Zařízení EM111 se k zařízením HARDWARIO připojuje přes **Modbus RTU** (RS-485):

- **GAUGER**: Zařízení GAUGER čte registry Modbus RTU z jednotky EM111 a odesílá data o energii do HARDWARIO Cloud.
- **CHESTER**: Zařízení CHESTER s rozšiřujícím modulem RS-485 může jednotku EM111 dotazovat a přeposílat data přes NB-IoT nebo LTE-M.
