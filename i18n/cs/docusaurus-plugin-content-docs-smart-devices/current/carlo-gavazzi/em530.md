# Carlo Gavazzi EM530 {#carlo-gavazzi-em530}

![Carlo Gavazzi EM530](/img/smart-devices/carlo-gavazzi-em530.webp)

**EM530** je třífázový elektroměr společnosti [Carlo Gavazzi](https://www.gavazziautomation.com/) pro externí měřicí transformátory proudu (CT). Hodí se k měření obvodů s vyššími proudy, kde přímé připojení není praktické.

## Klíčové parametry {#key-specifications}

| Parametr | Hodnota |
|---|---|
| Fáze | 3fázový, 4vodičový (+ nulový vodič) |
| Proudový vstup | Externí CT: sekundár 5 A |
| Napětí | 3× 230/400 V AC (50/60 Hz) |
| Přesnost | Třída 1 (činná energie) |
| Komunikace | Modbus RTU (RS-485) |
| Displej | LCD |
| Montáž | Na lištu DIN |
| Certifikace | CE |

## Měřené parametry {#measured-parameters}

- Činná energie (kWh import/export)
- Jalová energie (kVArh)
- Činný/jalový výkon po fázích a celkově
- Napětí, proud, účiník, frekvence

## Integrace s HARDWARIO {#hardwario-integration}

S HARDWARIO se elektroměr EM530 používá k monitorování spotřeby energie v průmyslu:

- **GAUGER**: Zařízení GAUGER čte přes Modbus RTU třífázová data o výkonu a odesílá je k analýze do HARDWARIO Cloud.
- **Podružné měření**: Sledování spotřeby energie po výrobních linkách, skupinách strojů nebo podlažích.
