# Carlo Gavazzi EM530 {#carlo-gavazzi-em530}

![Carlo Gavazzi EM530](/img/smart-devices/carlo-gavazzi-em530.webp)

**EM530** je třífázový elektroměr od [Carlo Gavazzi](https://www.gavazziautomation.com/) určený pro použití s externími měřicími transformátory proudu (CT). Je vhodný pro měření obvodů s vyššími proudy, kde je přímé připojení nepraktické.

## Klíčové parametry {#key-specifications}

| Parametr | Hodnota |
|---|---|
| Fáze | 3fázový, 4vodičový (+ nulový vodič) |
| Proudový vstup | Externí CT: sekundár 5 A |
| Napětí | 3× 230/400 V AC (50/60 Hz) |
| Přesnost | Třída 1 (činná energie) |
| Komunikace | Modbus RTU (RS-485) |
| Displej | LCD |
| Montáž | Na DIN lištu |
| Certifikace | CE |

## Měřené parametry {#measured-parameters}

- Činná energie (kWh import/export)
- Jalová energie (kVArh)
- Činný/jalový výkon po fázích a celkově
- Napětí, proud, účiník, frekvence

## Integrace s HARDWARIO {#hardwario-integration}

Elektroměr EM530 se používá v průmyslových aplikacích pro monitoring energií s HARDWARIO:

- **GAUGER**: Načítá třífázová data o výkonu přes Modbus RTU a odesílá je do HARDWARIO Cloud k analýze.
- **Podružné měření**: Monitoring spotřeby energie po výrobních linkách, skupinách strojů nebo podlažích.
