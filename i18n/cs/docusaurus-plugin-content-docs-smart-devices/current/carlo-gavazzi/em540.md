# Carlo Gavazzi EM540 {#carlo-gavazzi-em540}

![Carlo Gavazzi EM540](/img/smart-devices/carlo-gavazzi-em540.webp)

**EM540** je třífázový elektroměr s přímým připojením od [Carlo Gavazzi](https://www.gavazziautomation.com/), certifikovaný pro fakturační měření v třífázových instalacích do 65 A bez externích měřicích transformátorů proudu.

## Klíčové parametry {#key-specifications}

| Parametr | Hodnota |
|---|---|
| Fáze | 3fázový, 4vodičový (+ nulový vodič) |
| Proud | Přímé připojení do 65 A |
| Napětí | 3× 230/400 V AC (50/60 Hz) |
| Přesnost | Třída 1 (činná energie), certifikace MID |
| Komunikace | Modbus RTU (RS-485) |
| Displej | LCD |
| Montáž | Na DIN lištu (4,5 modulu) |
| Certifikace | MID (EC Certificate), CE |

## Měřené parametry {#measured-parameters}

- Činná energie (kWh import/export)
- Jalová energie (kVArh)
- Činný/jalový výkon po fázích a celkově
- Napětí, proud, účiník, frekvence

## Integrace s HARDWARIO {#hardwario-integration}

Zařízení EM540 je vhodné pro monitoring energií v malých a středních průmyslových aplikacích:

- **GAUGER**: Přímé připojení přes Modbus RTU k zařízení GAUGER pro přeposílání energetických dat v reálném čase do HARDWARIO Cloud.
- **Třífázový monitoring**: Ideální pro monitoring vzduchotechniky, kompresorů nebo výrobních zařízení napájených z třífázové sítě.
