# Carlo Gavazzi EM540 {#carlo-gavazzi-em540}

![Carlo Gavazzi EM540](/img/smart-devices/carlo-gavazzi-em540.webp)

**EM540** je třífázový elektroměr společnosti [Carlo Gavazzi](https://www.gavazziautomation.com/) pro přímé připojení. Má certifikaci pro fakturační měření v třífázových instalacích do 65 A a nepotřebuje externí měřicí transformátory proudu.

## Klíčové parametry {#key-specifications}

| Parametr | Hodnota |
|---|---|
| Fáze | 3fázový, 4vodičový (+ nulový vodič) |
| Proud | Přímé připojení do 65 A |
| Napětí | 3× 230/400 V AC (50/60 Hz) |
| Přesnost | Třída 1 (činná energie), certifikace MID |
| Komunikace | Modbus RTU (RS-485) |
| Displej | LCD |
| Montáž | Na lištu DIN (4,5 modulu) |
| Certifikace | MID (certifikát ES), CE |

## Měřené parametry {#measured-parameters}

- Činná energie (kWh import/export)
- Jalová energie (kVArh)
- Činný/jalový výkon po fázích a celkově
- Napětí, proud, účiník, frekvence

## Integrace s HARDWARIO {#hardwario-integration}

Elektroměr EM540 se hodí k monitorování spotřeby energie v menších a středních průmyslových provozech:

- **GAUGER**: Elektroměr se přes Modbus RTU připojí přímo k zařízení GAUGER, které data o energii v reálném čase přeposílá do HARDWARIO Cloud.
- **Třífázové měření**: Hodí se ke sledování systémů vytápění, větrání a klimatizace (HVAC), kompresorů nebo výrobních zařízení napájených ze třífázové sítě.
