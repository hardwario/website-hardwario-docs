# OnLogic CL210G-10 {#onlogic-cl210g-10}

![OnLogic CL210G-10](/img/smart-devices/onlogic-cl210g-10.webp)

**CL210G-10** je kompaktní bezventilátorový průmyslový počítač od společnosti [OnLogic](https://www.onlogic.com/) určený pro nepřetržitý provoz 24/7 v náročném průmyslovém prostředí bez aktivního chlazení.

## Klíčové parametry {#key-specifications}

| Parametr | Hodnota |
|---|---|
| Procesor | Intel Core i5 / i7 (10. generace, Tiger Lake-H) |
| Paměť | Až 64 GB DDR4 SO-DIMM |
| Úložiště | M.2 NVMe SSD (PCIe Gen 3) |
| Síť | 2× Gigabit LAN (Intel i225) |
| Rozšíření | Slot PCIe x16 v plné velikosti, M.2 2242 (SATA/USB) |
| Vstupní napětí | 12–36 V DC |
| Provozní teplota | 0 °C až 60 °C |
| Rozměry | Kompaktní, montáž na lištu DIN nebo na stůl |
| Certifikace | CE, FCC |

## Integrace s HARDWARIO {#hardwario-integration}

Počítač CL210G-10 slouží v nasazeních HARDWARIO jako **hostitel pro edge computing**:

- Běží na něm **HARDWARIO Cloud Connector**, který data lokálně ukládá do vyrovnávací paměti a přeposílá do cloudu
- Hostuje síťový server LoRaWAN **ChirpStack** nebo **The Things Stack** vedle zařízení CHESTER nebo bran EMBER
- Slouží jako **agregátor Modbus RTU/TCP** pro data ze zařízení GAUGER nebo z elektroměrů Carlo Gavazzi
- Běží na něm **Node-RED** nebo vlastní middleware, který zpracovává data a překládá protokoly
