# OnLogic CL210G-10 {#onlogic-cl210g-10}

![OnLogic CL210G-10](/img/smart-devices/onlogic-cl210g-10.webp)

**CL210G-10** je kompaktní bezventilátorový průmyslový počítač od [OnLogic](https://www.onlogic.com/), navržený pro nepřetržitý provoz 24/7 v náročných průmyslových prostředích bez aktivního chlazení.

## Klíčové parametry {#key-specifications}

| Parametr | Hodnota |
|---|---|
| Procesor | Intel Core i5 / i7 (10. generace, Tiger Lake-H) |
| Paměť | Až 64 GB DDR4 SO-DIMM |
| Úložiště | M.2 NVMe SSD (PCIe Gen 3) |
| Síť | 2× Gigabit LAN (Intel i225) |
| Rozšíření | PCIe x16 full-size slot, M.2 2242 (SATA/USB) |
| Vstupní napětí | 12–36 V DC |
| Provozní teplota | 0 °C až 60 °C |
| Rozměry | Kompaktní, montáž na DIN lištu nebo na stůl |
| Certifikace | CE, FCC |

## Integrace s HARDWARIO {#hardwario-integration}

Počítač CL210G-10 slouží v nasazeních HARDWARIO jako **hostitel pro edge computing**:

- Provoz **HARDWARIO Cloud Connector** pro lokální bufferování a přeposílání do cloudu
- Hostování LoRaWAN Network Serveru **ChirpStack** nebo **The Things Stack** vedle bran CHESTER nebo EMBER
- Funkce **agregátoru Modbus RTU/TCP** pro data z jednotky GAUGER nebo z elektroměrů Carlo Gavazzi
- Provoz **Node-RED** nebo vlastního middlewaru pro zpracování dat a překlad protokolů
