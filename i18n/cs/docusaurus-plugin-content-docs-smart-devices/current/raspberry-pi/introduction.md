# Raspberry Pi {#raspberry-pi}

[Raspberry Pi](https://www.raspberrypi.com/) vyrábí cenově dostupné a kompaktní výpočetní moduly a jednodeskové počítače, které se hojně používají v IoT, vestavěných systémech a aplikacích edge computingu.

---

**Compute Module 4 (CM4)** je kompaktní modul SoM (system-on-module) určený k začlenění do vlastního hardwaru. Na rozdíl od běžných spotřebitelských desek Raspberry Pi je CM4 určený pro vývoj průmyslových a komerčních produktů.

## Klíčové produkty {#key-products}
