# Podpora externích senzorů {#external-sensor-support}

Zařízení **STICKER Input** lze rozšířit o externí senzory a sondy připojené přes jeho vstupní rozhraní. Modul tak zvládne i náročné měřicí úlohy, kdy je potřeba snímat veličinu mimo samotné zařízení, například teplotu a vlhkost přímo na stroji, vibrace a pohyb nebo impulzy z průmyslových měřičů.

Každé podporované externí rozhraní má vlastní kapitolu, takže se seznam může s novými senzory rozšiřovat:

- **[MACHINE PROBE](./machine-probe.md)**: kompaktní multifunkční sonda s digitálními senzory na sběrnici 1-Wire.
- **[Teplotní sondy 1-Wire (Dallas)](./one-wire-dallas.md)**: samostatné teplotní senzory připojené jediným datovým vodičem.
- **[Rozhraní S0](./s0-interface.md)**: impulzní vstup pro odečet měřičů energií a průtoku.
