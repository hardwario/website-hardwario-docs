# Podpora externích senzorů {#external-sensor-support}

Zařízení **STICKER Input** lze rozšířit o externí senzory a sondy připojené přes jeho vstupní rozhraní. Modul tak zvládne i náročné měřicí úlohy, kdy je potřeba snímat veličinu mimo samotnou jednotku, například teplotu a vlhkost přímo na stroji, vibrace a pohyb nebo počítání pulzů z průmyslových měřičů.

Každé podporované externí rozhraní má vlastní kapitolu, takže se seznam může rozrůstat s přidáváním nových senzorů:

- **[MACHINE PROBE](./machine-probe.md)**: kompaktní multifunkční sonda s digitálními senzory na sběrnici 1-Wire.
- **[Teplotní sondy 1-Wire (Dallas)](./one-wire-dallas.md)**: samostatné teplotní senzory připojené jediným datovým vodičem.
- **[Rozhraní S0](./s0-interface.md)**: pulzní vstup pro odečet měřičů energií a průtoku.
