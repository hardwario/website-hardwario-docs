# Rozhraní S0 (pulzní výstup) {#s0-interface-pulse-output}

**Rozhraní S0** je standardizovaný pulzní výstup, který používá mnoho **měřičů energií a médií**: elektroměry, plynoměry, vodoměry a měřiče tepla. Každý pulz odpovídá definovanému množství spotřebované energie nebo média a zařízení STICKER Input tyto pulzy počítá, což umožňuje odečítat spotřebu na dálku přes síť LoRaWAN.

:::info

Podrobný popis zapojení S0 a konfigurace měření pulzů bude doplněn v samostatné sekci.

:::
