Vyvinuli jsme několik **nástrojů příkazové řádky**, aby bylo možné pracovat se systémem HARDWARIO TOWER i bez grafických aplikací.

Tyto nástroje lze použít k:
- Provozu vlastního serveru se všemi potřebnými nástroji, jak jsme probírali v [**předchozí kapitole**](../server-raspberry-pi/index.md)
- Vývoji firmwaru bez použití jakýchkoli **pokročilých grafických nástrojů**, více v [**sekci o vývoji firmwaru**](../firmware-development/development-with-cli-tools.md)
- Ukládání **MQTT zpráv** do **databáze Influx** pomocí nástroje **mqtt2influxdb**, více si můžete přečíst v [**jeho kapitole**](./mqtt-to-influx-db.md)


:::note

Máme také řadu grafických nástrojů. Pokud se o nich chcete dozvědět více, podívejte se na [**kapitolu Desktopové programování**](../category/desktop-programming) nebo [**kapitolu O HARDWARIO Code**](../firmware-development/about-hardwario-code.md)

:::
