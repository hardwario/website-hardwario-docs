Tato sekce popisuje, jak začít vyvíjet vlastní firmware pro zařízení HARDWARIO TOWER.

Hodí se to, pokud z našich hotových projektů potřebujete konkrétní funkce, nebo pokud chcete postavit vlastní projekt.

:::info

Tato sekce se věnuje nástrojům pro vývoj firmwaru. Pokud je už máte nebo znáte a chcete jen vidět příklady, jak firmware psát, přejděte do [**sekce Firmware SDK**](../firmware-sdk/index.md).

:::

Nabízíme tři způsoby, jak firmware psát a spravovat:

- [**HARDWARIO Code**](./about-hardwario-code.md): samostatná verze **Visual Studio Code** připravená speciálně pro vývoj firmwaru HARDWARIO TOWER
- [**HARDWARIO TOWER Extension**](./hardwario-extension-tutorial.md): rozšíření pro **Visual Studio Code** určené pro vývoj firmwaru HARDWARIO TOWER
- [**CLI Tools**](./development-with-cli-tools.md): sada nástrojů pro vývoj na strojích bez grafického rozhraní nebo pro ty, kdo prostě dávají přednost příkazové řádce

:::note

Pokud vás vývoj firmwaru nezajímá, podívejte se do sekce [**Programování na počítači**](../category/desktop-programming/), která popisuje náš další nástroj, aplikaci HARDWARIO Playground.

:::
