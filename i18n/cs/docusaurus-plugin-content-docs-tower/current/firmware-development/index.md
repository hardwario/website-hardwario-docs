Tato sekce se zaměřuje na to, jak začít vyvíjet vlastní firmware pro zařízení HARDWARIO TOWER.

Může se vám to hodit, pokud potřebujete konkrétní funkce z našich již existujících projektů nebo pokud si chcete vytvořit vlastní projekt.

:::info

Tato sekce se věnuje nástrojům pro vývoj firmwaru. Pokud je již máte nebo znáte a chcete jen vidět příklady, jak firmware psát, přejděte do [**sekce Firmware SDK**](../firmware-sdk/index.md).

:::

Nabízíme dva způsoby, jak firmware psát a spravovat:

- [**HARDWARIO Code**](./about-hardwario-code.md): samostatná verze **Visual Studio Code**, vytvořená speciálně pro vývoj firmwaru HARDWARIO TOWER
- [**HARDWARIO TOWER Extension**](./hardwario-extension-tutorial.md): rozšíření pro **Visual Studio Code** určené pro vývoj firmwaru HARDWARIO TOWER
- [**CLI Tools**](./development-with-cli-tools.md): sada nástrojů dostupná pro vývoj na strojích bez grafického rozhraní nebo pokud prostě preferujete práci v příkazové řádce

:::note

Pokud vás vývoj firmwaru nezajímá, můžete se podívat na sekci [**Desktop Programming**](../category/desktop-programming/), která popisuje náš další nástroj HARDWARIO Playground.

:::
