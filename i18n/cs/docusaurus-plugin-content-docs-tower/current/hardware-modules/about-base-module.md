## Vlastnosti {#features}
- Praktický stojan pro **modulární systém HARDWARIO TOWER**
- <b>Prototypovací plocha pro pájení</b> vlastních obvodů
- Gumové nožičky (**součástí balení**)
- Plastové klipy pro **montáž na DIN lištu (volitelné příslušenství)**
- Rozsah provozních teplot: -20 až 70 °C
- Mechanické rozměry: 88 x 55 mm
