## Vlastnosti {#features}
- Velké a robustní tlačítko pro **komfortní stisk**
- Životnost přes **jeden milion stisků**
- Rozsah provozních teplot: -20 až 60 °C
- Mechanické rozměry: 33 x 55 mm
