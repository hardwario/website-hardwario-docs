Pokud chcete začít používat TOWER ve svých domácích nebo firemních aplikacích,
budete potřebovat něco trvalejšího než [**HARDWARIO Playground**](../desktop-programming/about-playground.md).

Potřebujete tedy **server**, který poběží většinu času, bude sbírat data z připojených zařízení a vám jen předloží výsledky. Může zařízením také automaticky posílat příkazy, takže získáte základní automatizaci: například rozsvítí světla, když připojené zařízení HARDWARIO TOWER naměří nízkou osvětlenost.

Jako server můžete použít několik různých zařízení. Pro začátek doporučujeme [**Raspberry Pi**](https://www.raspberrypi.org), protože jde o poměrně **cenově dostupný** a **kvalitní produkt**.

Pokud už Raspberry Pi máte a chcete si zachovat svoje nastavení, server HARDWARIO TOWER zprovozníte i tak, stačí postupovat podle [**kapitoly Čistá instalace**](./installation-clean-os.md)

Pokud máte své první Raspberry Pi nebo nějaké nepoužívané, můžete podle [**kapitoly Předinstalovaný obraz**](./installation-os.md) stáhnout a nainstalovat náš připravený obraz.
