Pokud chcete začít používat TOWER ve svých domácích nebo firemních aplikacích,
budete potřebovat něco trvalejšího než [**HARDWARIO Playground**](../desktop-programming/about-playground.md).

To znamená, že budete chtít provozovat **server**, který může běžet většinu času, sbírat všechna data z připojených zařízení a jen vám prezentovat výsledky. Může také posílat zařízením některé automatické příkazy, takže získáte základní úroveň automatizace – například zapnutí světel, když ze svého připojeného zařízení HARDWARIO TOWER dostanete nízkou úroveň osvětlení.

Jako server můžete použít několik různých zařízení. Pro začátek doporučujeme [**Raspberry Pi**](https://www.raspberrypi.org), protože jde o poměrně **cenově dostupný** a **kvalitní produkt**.

Pokud už Raspberry Pi máte a chcete si zachovat svoje nastavení, server HARDWARIO TOWER můžete stejně rozchodit – stačí následovat [**kapitolu Čistá instalace**](./installation-clean-os.md)

Pokud jste právě získali své první Raspberry Pi nebo máte někde nepoužité, můžete podle [**kapitoly Předinstalovaný obraz**](./installation-os.md) stáhnout a nainstalovat náš připravený obraz.
