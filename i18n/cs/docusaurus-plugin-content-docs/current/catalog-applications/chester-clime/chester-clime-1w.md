# CHESTER Clime 1W {#chester-clime-1w}

**CHESTER Clime 1W** je varianta aplikace [**CHESTER Clime**](index.md) pro více externích teplotních sond **DS18B20** 1-Wire.

:::info Firmware

Tato varianta používá hlavní **[firmware CHESTER Clime](../../firmware/chester-clime/index.md)**, který podporu sond DS18B20 1-Wire obsahuje.

:::

## Rozdíly oproti aplikaci CHESTER Clime {#differences-from-chester-clime}

- Teplotu měří několika sondami DS18B20 1-Wire místo vlhkoměru CHESTER-S2.
- Krabička má 8 kabelových průchodek pro kabely sond.

## Hardware {#hardware}

Hardware této aplikace tvoří tyto položky (objednací kódy):

* `CHESTER-M-BCGLS`: Standardní základní deska
* `CHESTER-E8-LP`: Krabička s 8 kabelovými průchodkami (RM8L-4S)

Podrobnosti najdete na stránce [**Objednací kódy**](../../ordering-codes.md).
