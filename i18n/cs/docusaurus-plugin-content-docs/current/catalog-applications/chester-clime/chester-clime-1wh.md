# CHESTER Clime 1WH {#chester-clime-1wh}

**CHESTER Clime 1WH** je varianta aplikace [**CHESTER Clime**](index.md) s vlhkoměrem **CHESTER-S2** a více externími teplotními sondami **DS18B20** 1-Wire.

:::info Firmware

Tato varianta používá hlavní **[firmware CHESTER Clime](../../firmware/chester-clime/index.md)**, který podporu sond DS18B20 1-Wire i modulu CHESTER-S2 obsahuje.

:::

## Rozdíly oproti aplikaci CHESTER Clime {#differences-from-chester-clime}

- K vlhkoměru CHESTER-S2 přidává několik teplotních sond DS18B20 1-Wire.
- Krabička má 8 kabelových průchodek pro kabely sond.

## Hardware {#hardware}

Hardware této aplikace tvoří tyto položky (objednací kódy):

* `CHESTER-M-BCGLS`: Standardní základní deska
* `CHESTER-S2`: Externí vlhkoměr
* `CHESTER-E8-LP`: Krabička s 8 kabelovými průchodkami (RM8L-4S)

Podrobnosti najdete na stránce [**Objednací kódy**](../../ordering-codes.md).
