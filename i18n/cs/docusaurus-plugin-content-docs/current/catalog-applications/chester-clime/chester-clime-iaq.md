# CHESTER Clime IAQ {#chester-clime-iaq}

![CHESTER Clime IAQ](/img/chester/catalog-applications/chester-clime-iaq.webp)

**CHESTER Clime IAQ** je varianta aplikace [**CHESTER Clime**](index.md) pro měření kvality vnitřního ovzduší.

:::info Firmware

Tato varianta používá **[firmware CHESTER Clime IAQ](../../firmware/chester-clime/chester-clime-iaq.md)**.

:::

## Rozdíly oproti aplikaci CHESTER Clime {#differences-from-chester-clime}

- Místo externího vlhkoměru měří integrovaný multisenzor **CHESTER-S1**: teplotu, vlhkost, osvětlenost, koncentraci CO₂ a atmosférický tlak a senzorem PIR detekuje pohyb.
- Hlásí stisky tlačítka a dává zvukovou a světelnou odezvu.
- Barva LED v tlačítku ukazuje úroveň koncentrace CO₂.
- Napájí se externě 6–28 V přes modul **CHESTER-X10** se záložní baterií Li-Ion.

## Hardware {#hardware}

Hardware této aplikace tvoří tyto položky (objednací kódy):

* `CHESTER-M-BCGLS`: Standardní základní deska
* `CHESTER-S1-BCMP`: Integrovaný multisenzor
* `CHESTER-X10`: Externí napájení 6–28 V s baterií Li-Ion
* `CHESTER-E7-LP`: Krabička s pigtailem SMA

Podrobnosti najdete na stránce [**Objednací kódy**](../../ordering-codes.md).
