# CHESTER Clime RTD {#chester-clime-rtd}

**CHESTER Clime RTD** je varianta aplikace [**CHESTER Clime**](index.md) pro dva externí čtyřvodičové teplotní senzory Pt1000.

:::info Firmware

Tato varianta používá **[firmware CHESTER Clime RTD](../../firmware/chester-clime/chester-clime-rtd.md)**.

:::

## Rozdíly oproti aplikaci CHESTER Clime {#differences-from-chester-clime}

- Teplotu měří dvěma čtyřvodičovými sondami Pt1000 na modulu **CHESTER-X3A** místo vlhkoměru CHESTER-S2.
- Krabička má 2 kabelové průchodky PG7 pro kabely sond.

## Hardware {#hardware}

Hardware této aplikace tvoří tyto položky (objednací kódy):

* `CHESTER-M-BCGLS`: Standardní základní deska
* `CHESTER-X3A:A`: Rozhraní pro 2x Pt100/Pt1000
* `CHESTER-E13-LP`: Krabička s pigtailem SMA a 2 kabelovými průchodkami PG7

Podrobnosti najdete na stránce [**Objednací kódy**](../../ordering-codes.md).
