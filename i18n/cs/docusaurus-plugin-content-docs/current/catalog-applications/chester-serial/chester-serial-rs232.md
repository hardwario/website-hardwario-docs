# CHESTER Serial RS-232 {#chester-serial-rs-232}

**CHESTER Serial RS-232** je varianta aplikace [**CHESTER Serial**](index.md) s rozšiřujícím modulem **CHESTER-X12**. Je určená pro spojení bod-bod s jedním periferním zařízením, se staršími zařízeními nebo se senzory, které potřebují přímé sériové spojení.

:::info Firmware

Tato varianta používá **[firmware CHESTER Serial RS-232](../../firmware/chester-serial/chester-serial-rs232.md)**, který pracuje se senzorem CO₂ MicroSENS 180-HS a se čtečkou RFID Promag MF7S.

:::

## Rozdíly oproti aplikaci CHESTER Serial {#differences-from-chester-serial}

* **Rozhraní:** neizolovaná RS-232
* **Topologie:** spojení bod-bod
* **Kapacita:** jedno zařízení (spojení 1:1)

## Hardware {#hardware}

Hardware této aplikace tvoří tyto položky (objednací kódy):

* `CHESTER-M-CGLS`: Standardní základní deska
* `CHESTER-X12`: Modul rozhraní RS-232
* `CHESTER-E2-LP`: Krabička s pigtailem SMA

Podrobnosti najdete na stránce [**Objednací kódy**](../../ordering-codes.md).
