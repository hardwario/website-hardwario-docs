# CHESTER wM-Bus DC {#chester-wm-bus-dc}

**CHESTER wM-Bus DC** je varianta aplikace [**CHESTER wM-Bus**](index.md) napájená externím adaptérem 230 V.

:::info Firmware

Tato varianta používá hlavní **[firmware CHESTER wM-Bus](../../firmware/chester-wm-bus/index.md)**.

:::

## Rozdíly oproti aplikaci CHESTER wM-Bus {#differences-from-chester-wm-bus}

- Napájí se externím síťovým adaptérem DC (230 V) místo šesti alkalických článků „D“.
- Základní deska má superkondenzátory (`CHESTER-M-CS` místo `CHESTER-M-CES`).
- Hodí se pro konfigurace, které [**příklady konfigurací**](../../firmware/chester-wm-bus/index.md#example-configurations) označují jako nevhodné pro bateriovou variantu.

## Hardware {#hardware}

Hardware této aplikace tvoří tyto položky (objednací kódy):

* `CHESTER-M-CS`: Standardní základní deska se superkondenzátory
* `CHESTER-B1-DLW`: Deska B1 se šesti držáky lithiových článků D a modulem wM-Bus

Podrobnosti najdete na stránce [**Objednací kódy**](../../ordering-codes.md).
