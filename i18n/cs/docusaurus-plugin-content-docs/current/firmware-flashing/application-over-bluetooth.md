# Aplikace přes Bluetooth {#application-over-bluetooth}

Použijte mobilní aplikaci [HARDWARIO Manager](../platform-connectivity/hardwario-manager.md) a postupujte podle kapitoly [Aktualizace firmwaru](../platform-connectivity/hardwario-manager.md#firmware-update).

:::caution

Tato metoda vyžaduje, aby na zařízení CHESTER již běžela funkční aplikace s podporou Bluetooth. Pokud zařízení CHESTER v seznamu Bluetooth zařízení nevidíte, musíte použít [metodu přes J-Link](./application-over-j-link.md).

:::
