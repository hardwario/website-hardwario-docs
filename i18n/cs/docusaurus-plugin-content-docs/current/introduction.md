# CHESTER {#chester}

**HARDWARIO CHESTER** je vysoce konfigurovatelná platforma IoT pro sítě **LPWAN**. Jejím hlavním úkolem je připojit k internetu co nejvíc zařízení a prostředí, a to hlavně z míst, kam nevede elektrická síť ani běžné připojení k internetu.

:::

## Typické využití {#typical-use-cases}

- Vzdálený monitoring v místech bez elektrické sítě nebo internetu
- Sledování polohy a stavu zařízení v sítích LoRaWAN
- Chytré zemědělství: monitoring vlhkosti půdy, meteorologických podmínek a zavlažování
- Průmyslová automatizace
- Spolehlivý provoz v náročném a drsném prostředí

## Klíčové vlastnosti {#key-features}

| Vlastnost | Popis |
|---|---|
| **Multi-Radio LPWAN** | Rádiové technologie NB-IoT, LTE-M, LoRaWAN, BLE a GNSS v jedné platformě. |
| **Katalogové aplikace** | Hotový firmware pro běžné úlohy měření a řízení. |
| **Rozšiřující moduly** | Rozšiřitelný hardware pro připojení senzorů a externích prostředí. |
| **HARDWARIO Cloud** | Správa a monitoring přes platformu HARDWARIO Cloud. |
| **Firmware SDK** | Otevřené SDK pro tvorbu plně vlastních aplikací. |
