# CHESTER {#chester}

**HARDWARIO CHESTER** je vysoce konfigurovatelná IoT platforma **LPWAN**. Jejím hlavním úkolem je připojit k internetu co nejvíce zařízení a prostředí, zejména z míst, kde není standardní připojení k elektrické síti a internetu.

## Typické případy použití {#typical-use-cases}

- Systémy vzdáleného monitoringu v místech bez standardního napájení nebo internetu
- Sledování majetku a monitorování stavu v sítích LoRaWAN
- Chytré zemědělství: monitoring vlhkosti půdy, meteorologických podmínek a zavlažování
- Řešení průmyslové automatizace
- Spolehlivé nasazení v náročných a nehostinných prostředích

## Klíčové vlastnosti {#key-features}

| Vlastnost | Popis |
|---|---|
| **Multi-Radio LPWAN** | Rádiové technologie NB-IoT, LTE-M, LoRaWAN, BLE a GNSS v jedné platformě. |
| **Katalogové aplikace** | Firmware připravený k použití pro běžné případy měření a řízení. |
| **Rozšiřující moduly** | Rozšiřitelný hardware pro připojení senzorů a externích prostředí. |
| **HARDWARIO Cloud** | Správa a monitoring prostřednictvím platformy HARDWARIO Cloud. |
| **Firmware SDK** | Otevřené SDK pro tvorbu plně vlastních aplikací. |
