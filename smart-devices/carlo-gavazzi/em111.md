# Carlo Gavazzi EM111

![Carlo Gavazzi EM111](/img/smart-devices/carlo-gavazzi-em111.webp)

The **EM111** is a compact DIN-rail single-phase energy meter from [Carlo Gavazzi](https://www.gavazziautomation.com/), certified for revenue-grade energy measurement with Modbus RTU communication.

## Key Specifications

| Parameter | Value |
|---|---|
| Phases | 1-phase, 2-wire |
| Current | Direct connection up to 32 A |
| Voltage | 230 V AC (50/60 Hz) |
| Accuracy | Class 1 (active energy), MID certified |
| Communication | Modbus RTU (RS-485) |
| Display | LCD, 7-digit |
| Mounting | DIN-rail (2 modules) |
| Certifications | MID (EC Certificate), CE |

## Measured Parameters

- Active energy (kWh import/export)
- Active power (W)
- Voltage (V), Current (A), Power factor

## HARDWARIO Integration

The EM111 connects to HARDWARIO devices via **Modbus RTU** (RS-485):

- **GAUGER**: The GAUGER device reads Modbus RTU registers from the EM111 and sends energy data to HARDWARIO Cloud.
- **CHESTER**: CHESTER with RS-485 extension module can poll the EM111 and forward data via NB-IoT or LTE-M.
