# Carlo Gavazzi EM530

![Carlo Gavazzi EM530](/img/smart-devices/carlo-gavazzi-em530.webp)

The **EM530** is a three-phase energy meter from [Carlo Gavazzi](https://www.gavazziautomation.com/) designed for use with external current transformers (CTs). It is suitable for monitoring higher-current circuits where direct connection is impractical.

## Key Specifications

| Parameter | Value |
|---|---|
| Phases | 3-phase, 4-wire (+ neutral) |
| Current Input | External CT: 5 A secondary |
| Voltage | 3× 230/400 V AC (50/60 Hz) |
| Accuracy | Class 1 (active energy) |
| Communication | Modbus RTU (RS-485) |
| Display | LCD |
| Mounting | DIN-rail |
| Certifications | CE |

## Measured Parameters

- Active energy (kWh import/export)
- Reactive energy (kVArh)
- Active/reactive power per phase and total
- Voltage, current, power factor, frequency

## HARDWARIO Integration

The EM530 is used in industrial energy monitoring applications with HARDWARIO:

- **GAUGER**: Reads three-phase power data via Modbus RTU and sends it to HARDWARIO Cloud for analysis.
- **Submetering**: Monitoring energy usage per production line, machine group, or floor.
