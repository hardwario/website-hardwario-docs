# Carlo Gavazzi EM540

![Carlo Gavazzi EM540](/img/smart-devices/carlo-gavazzi-em540.webp)

The **EM540** is a three-phase direct-connection energy meter from [Carlo Gavazzi](https://www.gavazziautomation.com/), certified for revenue-grade measurement in three-phase installations up to 65 A without external current transformers.

## Key Specifications

| Parameter | Value |
|---|---|
| Phases | 3-phase, 4-wire (+ neutral) |
| Current | Direct connection up to 65 A |
| Voltage | 3× 230/400 V AC (50/60 Hz) |
| Accuracy | Class 1 (active energy), MID certified |
| Communication | Modbus RTU (RS-485) |
| Display | LCD |
| Mounting | DIN-rail (4.5 modules) |
| Certifications | MID (EC Certificate), CE |

## Measured Parameters

- Active energy (kWh import/export)
- Reactive energy (kVArh)
- Active/reactive power per phase and total
- Voltage, current, power factor, frequency

## HARDWARIO Integration

The EM540 is suitable for energy monitoring in small-to-medium industrial applications:

- **GAUGER**: Direct Modbus RTU connection to GAUGER for real-time energy data forwarding to HARDWARIO Cloud.
- **Three-phase monitoring**: Ideal for monitoring HVAC systems, compressors, or production equipment operating on three-phase power.
