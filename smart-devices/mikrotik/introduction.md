# MikroTik

[MikroTik](https://mikrotik.com/) is a Latvian manufacturer of networking equipment and wireless systems used across ISPs, industrial networks, and IoT deployments worldwide.

---

MikroTik's **RouterBOARD** platform provides LoRaWAN gateway capabilities, enabling connection of LoRaWAN sensors to network servers such as ChirpStack or The Things Stack.

## Key Products

| Product | Description |
|---|---|
| [**RouterBOARD LoRa**](/smart-devices/mikrotik/routerboard-lora) | Compact LoRaWAN gateway based on MikroTik RouterOS with an integrated LoRa concentrator card. Supports 8-channel LoRa reception and runs standard Semtech packet forwarder software. |

## Typical Use Cases with HARDWARIO

- **LoRaWAN network server gateway**: Forwarding packets from CHESTER or STICKER devices to a ChirpStack or The Things Stack network server.
- **Private LoRaWAN network**: Building a localized, indoor LoRaWAN network for a single building or campus.
