# External Sensor Support

**STICKER Input** can be extended with external sensors and probes connected through its input interface. This allows the module to handle demanding measurement tasks where a quantity needs to be sensed away from the unit itself, for example temperature and humidity directly on a machine, vibration and motion, or pulse counting from industrial meters.

Each supported external interface has its own chapter, so the list can grow as new sensors are added:

- **[MACHINE PROBE](./machine-probe.md)**: a compact multi-function probe with digital sensors on a 1-Wire bus.
- **[1-Wire temperature probes (Dallas)](./one-wire-dallas.md)**: standalone temperature sensors connected over a single data wire.
- **[S0 interface](./s0-interface.md)**: a pulse input for reading energy and flow meters.
