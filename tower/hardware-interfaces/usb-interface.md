title: USB Interface
description: USB connectivity options for the HARDWARIO TOWER Core Module, Radio Dongle, and Bridge Module.
---

USB behavior depends on the TOWER module connected to the host:

- The [Core Module](../hardware-modules/about-core-module.md) uses its Micro-USB connector for power, host communication, and firmware programming through its DFU bootloader.
- The [Radio Dongle](../hardware-modules/about-radio-dongle.md) connects a computer or gateway to the TOWER sub-GHz radio network through USB.
- The [Bridge Module](../hardware-modules/about-bridge-module.md) exposes supported module interfaces to a USB host through its FT260 USB bridge.

For the desktop workflow, see [Playground installation](../desktop-programming/playground-installation.md), [radio network management](../desktop-programming/radio-network-management.md), and [firmware flashing](../desktop-programming/firmware-flashing.md).
